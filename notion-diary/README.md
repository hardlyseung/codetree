# 📔 Notion Diary

내 노션(Notion) 페이지를 그대로 불러와 **다이어리처럼** 보여주는 웹앱입니다.
달력에서 날짜를 누르면 그날 쓴 노션 페이지가 일기장 종이 위에 펼쳐지고, 새 일기를 쓰면 노션에 바로 저장됩니다.

- 외부 패키지 없음 (Node.js 18+ 만 있으면 실행)
- 달력 · 이번 달 기록 수 · 연속 기록 · 자주 쓴 아이콘 통계
- 노션 블록 지원: 문단, 제목, 리스트, 체크박스, 인용, 콜아웃, 토글, 코드, 이미지, 구분선, 북마크, 글자 색/서식
- 페이지 아이콘(이모지)은 그날의 기분으로, 커버 이미지는 일기 상단에 표시
- 다크 모드, 모바일 화면 지원 / 키보드 ←, → 로 달 이동

## 빠르게 둘러보기 (데모)

```bash
cd notion-diary
npm run demo        # http://localhost:3000
```

## 내 노션과 연동하기

1. **통합 만들기** – <https://www.notion.so/my-integrations> 에서 *새 통합* → "내부(Internal)" 선택 → **내부 통합 시크릿** 복사
2. **페이지 공유** – 일기로 쓸 노션 페이지(또는 데이터베이스) 오른쪽 위 `•••` → **연결(Connections)** → 방금 만든 통합 추가
3. **설정 파일 작성**
   ```bash
   cp .env.example .env
   # .env 의 NOTION_TOKEN 에 시크릿 붙여넣기
   ```
4. **실행**
   ```bash
   npm start           # http://localhost:3000
   ```

### 두 가지 모드

| 모드 | 설정 | 동작 |
|---|---|---|
| 전체 페이지 모드 | `NOTION_DATABASE_ID` 비움 | 통합에 공유된 모든 페이지를 **생성일** 기준으로 달력에 배치 (읽기 전용) |
| 일기 DB 모드 (추천) | `NOTION_DATABASE_ID` 지정 | 데이터베이스의 **날짜 속성**(없으면 생성일) 기준으로 배치, ✏️ 버튼으로 새 일기를 노션에 저장 |

데이터베이스 ID는 DB를 전체 페이지로 열었을 때 URL의 `notion.so/<워크스페이스>/`**`이_32자리`**`?v=...` 부분입니다.
DB에는 *제목* 속성과 *날짜* 속성 하나씩만 있으면 되고, `선택`/`다중 선택` 속성은 해시태그로 표시됩니다.

## 구조

```
notion-diary/
├─ server.js        # HTTP 서버 + API (/api/info, /api/entries, /api/entries/:id)
├─ notion.js        # Notion API 호출, 블록 → HTML 변환
├─ demo.js          # 토큰 없이 볼 수 있는 샘플 데이터
├─ notion.test.js   # npm test
└─ public/index.html  # 다이어리 화면 (달력, 목록, 읽기, 쓰기)
```

> 시크릿은 서버(`.env`)에만 있고 브라우저로 전달되지 않습니다. `.env`는 `.gitignore`에 포함되어 있어요.
